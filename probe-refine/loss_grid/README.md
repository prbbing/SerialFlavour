# Loss Grid

`probe-refine/` 按 probe 手段组织代码与分析；本目录用于损失权重网格实验，研究上游 jet、origin、pair 任务的权重如何影响冻结表征、主任务性能和下游 refinement 收益。研究背景见 `../../docs/probe_design.md` 的 E3。

## 分析目标

在固定数据划分、模型结构、训练预算和选择准则下，改变辅助任务 loss 权重，比较 native head、强 embedding-only 与辅助增强读出。分别报告绝对性能、辅助读出增量和 refinement gap，避免把原 head 变差造成的大 gap 解释为表征改善。

## 组织与原则

- 此 probe 的专用代码、实验配置与结果分析集中在本目录，后续根据实际需要组织文件，不预先增加子目录。
- 包含无辅助监督及单项辅助监督对照；某个辅助 loss 关闭后，其未训练 head 的输出不能当作有效辅助信号。
- 保持事件级训练、验证、测试边界，测试集不用于选权重；保留逐 seed 配对结果并说明聚合口径。
- 每次实验记录 loss 权重、配置、划分、checkpoint、seed 和产物路径；输出与可写缓存按实验隔离。

当前仅建立目录与说明，尚未实现或执行网格实验；具体权重范围和运行规模待后续任务确定。
