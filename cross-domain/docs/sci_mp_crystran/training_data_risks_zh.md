# MP＋CrystalTransformer：从头训练、样本量与预训练边界

更新：2026-10-03。本文记录潜在实验设计问题，不将其写成已经观测到的过拟合或负结果，也不授权扩大数据、加载预训练权重或启动训练。实际配置仍是 [cluster_20k.json](../../experiments/sci_mp_crystran/config/cluster_20k.json)，运行与资源说明见 [集群说明](cluster_run_zh.md)。

## 1. 当前设置与尚未解决的问题

三种上游均在 A 上从随机初始化训练，不加载作者或 MP* 预训练权重。上游为 64/4/4/128；完整冻结后，仅训练下游 128/64/32 读出。下游残差输出层初始为零，因此 epoch 0 预测等于 native，并由 B_val 决定是否保留；这不等于下游使用外部预训练权重。

| 阶段 | 可训练参数口径 | 训练材料 | 模型选择材料 |
|---|---:|---:|---:|
| ST 上游 | 145,697 | A_train 11,200 | A_val 1,000 |
| MT 上游 | 145,698 | A_train 11,200 | A_val 1,000 |
| 同 MT 架构 main-only | 总参数 145,698；主损失梯度覆盖 141,473 | A_train 11,200 | A_val 1,000 |
| 每个下游读出 | 43,649；上游全部冻结 | B_train 2,800 | B_val 1,000 |

总池 20,000 含上述分区及 Y 4,000。5×5 seeds、多个 epochs 或晶胞内的多个原子不能计为新增独立材料。主/辅助任务是材料级 Eg/Ef 标量，没有逐原子任务标签。

缩小模型后，上游参数约为 Jet tagging 122,077 设置的 1.19 倍，但输入、监督密度、任务与归纳偏置不同，不能由参数接近推断相同的样本效率，也没有通用的参数/样本比例合格线。当前集群配置尚未训练；历史 1,024 材料 CPU smoke 只证明工程闭环，不证明当前表示质量、样本充分性或方法有效。

## 2. 为什么这会影响方法论结论

- **上游质量可能不足。** 主任务或辅助任务没有学好时，下游无增益可能来自弱表征、弱辅助预测、优化问题或表示限制，不能直接解释为 frozen post-refinement 普遍无效。
- **正增益也可能依赖数据稀缺。** 辅助监督的收益可能主要是有限数据条件下的正则化作用；需要对照同架构 main-only，并将其与冻结后辅助预测对强、同容量 embedding-only 的增量分开报告。
- **下游容量同样需要关注。** 43,649 个读出参数只有 2,800 个 B_train 材料；残差初始化、保留 epoch 0、早停和容量匹配控制比较条件，不能单独证明泛化可靠。
- **几何限制影响样本效率。** 当前没有显式周期邻居、对称性架构或作者坐标增强；历史 smoke 存在排序/平移/旋转敏感。扩大数据或引入预训练不能自动消除这些限制。

解释结果时，应关注 A 内主/辅助训练与验证误差、辅助预测相对于训练部分常数基线的质量、B_train/B_val 差距，以及同 seed 的配对增益与方向。主/辅助任务质量诊断若需新增输出或审计，仅在相应开发授权后实现，不使用 Y 选择架构、任务或预算。当前静态检查未提供这些新诊断证据。

## 3. 不用预训练是否合理

不用预训练有明确的研究目的：控制上游数据与标签暴露，使真正的 ST 只接受主任务监督，MT 仅在相同 A 中增加 Ef 监督。这允许研究独立 B 上的冻结读出，但数据边界严格并不等于上游训练已充分。

CrystalTransformer 论文的 MP 数据有 60,000/5,000/4,239 的训练/验证/测试分区，MP* 有 134,243 个材料并使用 80/10/10 分区。主要嵌入迁移实验先在 MP* 上训练前端，再向 MP 后端迁移；论文也评估从头训练的 CrystalTransformer。我们的 A_train 11,200、较小架构和完整冻结协议均不同，不能借论文成绩证明当前预算足够。[论文数据、预训练流程与从头训练评估](https://www.nature.com/articles/s41467-025-56481-x)

**当前结论：从头训练是合理的受控选择；20k 总池可以检验有限数据条件，但目前没有证据确认其足以支撑稳定的方法论结论。** 不把“没有预训练”或“参数接近 Jet”当成样本充分性的证明。

## 4. 预训练可作为另一种协议，但不能直接替换

| 问题 | 需要明确的边界 |
|---|---|
| B/Y 标签暴露 | MP* 中可能包含相同或等价材料；若预训练已使用 B/Y 的 Eg/Ef 标签，就破坏当前标签隔离协议。需核对 material ID、等价结构、任务标签和实际训练分区，不能只凭快照年份判定无重叠 |
| 无标签输入暴露 | 仅接触 B/Y 结构的自监督预训练不同于目标标签泄漏，但属于额外输入暴露，应单独声明；严格独立版本应排除该重叠 |
| ST/MT 初始条件 | 采用预训练时保持相同初始权重和资源，记录预训练数据、目标与选择过程；共同多任务监督预训练后仅 Eg 微调，只能称“共同预训练后的 main-only 微调”，不能称完全未接受辅助监督的 ST |
| 权重形状 | 作者默认 256/8 架构的完整权重不能直接加载到当前 64/4 网络；只迁移元素嵌入表、部分权重或做压缩均属于另行声明的适配 |
| 结论范围 | 预训练实验回答“共同预训练条件下的增量”，从头训练实验回答“受控 A 监督下的增量”；不混合两个资源条件汇总收益 |

若今后选择预训练，需建立与 B/Y 无重叠的可审计预训练来源或重新制定并明确标注暴露协议，再使用新实验身份。本文没有核验可直接使用的无重叠 checkpoint，也没有加载任何预训练权重。

## 5. 后续选择与当前状态

优先方向是保持已经确认的小模型和从头训练协议，在用户明确授权后考虑扩大正式数据预算。仅作规划示例：若筛选去重后可取 50k 总池，沿用 56/5/14/5/20 划分会得到 A_train 28,000、A_val 2,500、B_train 7,000、B_val 2,500、Y 10,000；这不保证已足够，也不表示当前配置已改为 50k。扩大前还需核验快照实际有效 N、候选池采样/去重逻辑和资源，不能只修改目标数量。

若保持 20k，应将结论限定为这一有限数据条件，完整报告弱辅助预测、上游未充分学习、过拟合与任务负迁移等替代解释。当前仅记录问题与方案，不增加 pilot 或子矩阵前置流程，不自动扩大矩阵、改预训练或调整对称性处理。

当前状态：历史 CPU smoke v3 已完成；集群 v2、当前 smoke v5 均未执行。新增三层读出、多 seed 统计和集群恢复代码只有静态检查及只读 dry-run 证据，尚无新 GPU 数值、样本充分性或预训练收益的验证。
